# Feature Specification: GUI Workflow Acceptance — Local `GET /health`

**Feature ID**: `gui-workflow-acceptance` · **Date**: 2026-09-07 · **Status**: 仅需求文档（退回修改后的精简重写，不新增需求）

**Scope note**: 本轮只产出需求与澄清文档，不实现业务代码、不运行任何命令；文中全部验收测试标记为未执行。

## Actors

- 本地操作者与探测/测试客户端（人工监控与 `node:test` 自动执行器）：经回环接口匿名访问 `127.0.0.1:3001`，只需存活应答。
- 健康服务与其他本机进程：前者执行下述路由规则；后者只能得到规定的 404/405 结果，不获得数据、控制权或会话。

## Flows

- F-01 成功探测：客户端发送 `GET /health`（含查询串变体）；服务返回 `200`，头 `Content-Type: application/json`，正文恰为 `{"ok":true}`，响应完整终止。
- F-02 路径未匹配：非 `/health` 路径的任意请求返回 `404`，未知路径上的非 GET 请求（如 `POST /nope`）同样先按路径判定，即 404 优先于 405。
- F-03 方法不允许：`/health` 上的非 `GET` 方法（POST/PUT/PATCH/DELETE/HEAD/OPTIONS）返回 `405`；停止进程后释放监听端口。

## Rules

- R-01 健康资源是唯一、精确、大小写敏感的 `/health` 路径：无别名、无重定向、不做尾斜杠或大小写归一化（`/health/`、`/HEALTH`、`/healthz`、`/` 均为 404）。
- R-02 成功响应为固定字节：正文恰为 11 字节 `{"ok":true}`，无空白、换行或动态字段；`Content-Type` 发出裸媒体类型 `application/json`，断言时大小写不敏感并容忍可选 `charset` 参数。
- R-03 服务无状态且配置不可变：仅绑定 IPv4 字面量 `127.0.0.1:3001`（不监听通配地址），重复与并发请求应答一致，不回显请求内容。

## Permissions

需求明确排除登录：无认证、无授权、无角色，凡能到达回环端口的客户端拥有相同的匿名只读访问。端口 3001 为非特权端口，无需提权；唯一的访问控制即回环绑定本身（R-03）。

## Data and Privacy

仅在内存读取方法与路径以选择状态码；无持久化、无会话、无个人数据、无凭据，响应不回显请求内容（R-03）。日志非需求，默认不记录；若实现附带诊断输出，不得改变 HTTP 应答或落盘数据。

## Integrations

仅使用 Node.js 24 内置模块：`node:http` 提供服务，`node:test` 与 `node:assert` 承担测试。无数据库、缓存、消息队列、外部 API、反向代理、TLS、容器或 CI 集成；对外契约只有 `GET /health` 一个请求形状与 200/404/405 三种结果。

## Non-Functional Requirements

只保留用户明确要求的约束：必须能用 Node.js 24 内置模块运行且无新增依赖、无安装步骤；服务仅绑定 `127.0.0.1:3001`。本轮不设定延迟、并发量、启动耗时或跨平台一致性等自拟指标（原稿中的此类数值已删除）。

## Non-Goals

本轮不产出业务代码、测试代码或配置文件。功能排除：认证/授权、限流、会话；数据库与任何持久化；HTTPS/TLS、HTTP/2、自定义主机或端口、IPv6；更丰富的健康信息（依赖检查、版本、uptime、时间戳）；`/health` 之外的端点与根路径页面；CORS、内容协商、请求日志。性能与容量目标同样不在本轮范围内。

## Acceptance Criteria

验收标准保持 5 项稳定 ID（涵盖成功响应、404、405、仅本机/无外部依赖、`node:test` 验证）；本轮一律标记为未执行。

1. AC-001: `GET /health`（含带查询串变体）返回状态 200、`Content-Type: application/json`、正文与 `{"ok":true}` 逐字节相等，且响应完整终止。未执行。
2. AC-002: 所有非 `/health` 路径请求返回 404，包括 `/`、`/health/`、`/healthz`、`/HEALTH` 以及未知路径上的 `POST /nope`。未执行。
3. AC-003: `/health` 上的所有非 `GET` 方法（POST、PUT、PATCH、DELETE、HEAD、OPTIONS）请求返回 405。未执行。
4. AC-004: 服务仅监听 `127.0.0.1:3001`、不接受非回环连接，且交付零新增依赖（无安装步骤，仅导入 Node.js 内置模块）。未执行。
5. AC-005: 以 `node:test` 编写并运行的测试套件覆盖 AC-001–AC-004，全部通过且退出码为 0。未执行——本轮未编写或运行任何测试。
