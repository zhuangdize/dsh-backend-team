## 待用户确认的问题

### Q1: 重复查询参数取值
- **上下文**: Rules FR-006 / AC-007。
- **需要确认**: `?name=张三&name=李四` 取第一个值，还是最后一个值，或是视为非法输入？
- **建议**: A = 取第一个值（当前默认，D-1）；B = 取最后一个值；C = 返回访客；Custom = 其它规则。

### Q2: 演示接口的承载方式
- **上下文**: Integrations 一节。约束「不修改任何已有文件」意味着无法在既有服务入口里注册新路由。
- **需要确认**: 演示接口是否作为 `src/greeting-demo/` 内**独立启动的原生 http 监听**（推荐，完全自包含、可被内置测试直接覆盖），还是希望以「仅新增文件」的方式被既有服务自动加载？
- **建议**: A = 独立 demo 监听/独立入口（当前默认）；B = 既有服务具备插件式自动发现机制时由其加载；C = 仅提供纯函数 + 处理器，由测试环境挂载，不提供常驻进程。

### Q3: 非 GET 方法访问 `/greeting` 的响应
- **上下文**: Rules FR-001 只约束了 `GET`。
- **需要确认**: 对 `POST /greeting` 等请求返回 404 还是 405？
- **建议**: A = 404（与「不存在的路径」一致，最省事）；B = 405 + `Allow: GET`；C = 不在演示范围内、不要求测试覆盖。
