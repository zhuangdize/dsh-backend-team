# 开发任务恢复说明

恢复只从最后一个“已验证并被父级确认”的垂直切片继续。中断中的 Agent handoff 会标记为 `interrupted`，不会因为存在输出文件就自动视为完成。

恢复前依次检查：

1. 当前工作区仍是原项目边界，Git 基线和用户未提交改动没有被覆盖。
2. 需求、架构、依赖和安装批准仍有效，批准文件哈希与当前文件一致。
3. 所有 ownership lease、补丁快照和 handoff 仍能校验；无法校验的切片先回滚或重新审阅。
4. 预算、运行时版本、命令和验证证据仍可用；工具不可用时标记为 `blocked`。
5. 先重新验证最后一个已接受切片，再按依赖顺序恢复后续切片。

恢复不会重跑已验证的切片。未验证的写入必须先与快照和用户改动做对比；存在冲突时暂停并要求人工确认。
